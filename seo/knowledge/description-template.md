The owner's own wording (his baptism listing, 2026-09-30). **Change only what describes the book** — the
parts in `{…}`. Everything else stays word for word. The page count is always **30-page** (the owner,
2026-10-04: 14 story spreads + dedication + afterword), whatever the book's files hold. Write `[Name]`
where the child's name goes; say "on the cover" only when the cover title holds `{Name}`
(`agent/book-text.md`, "Cover").
