# Джерела власника

Сюди кладуться матеріали, які власник дає для вікі: тексти, скриншоти, документи, експорти.
Файли тут **не змінюються** — агент лише читає їх і переносить знання в сторінки вікі
(операція «додавання джерела», див. [../dev/wiki-rules.md](../dev/wiki-rules.md)).

- Назва файлу: `РРРР-ММ-ДД-коротко-про-що.ext`.
- Не класти сюди ключі, паролі, справжні адреси покупців та інші особисті дані — папка в git.
- Великі або приватні файли краще не комітити; достатньо короткого конспекту в сторінці вікі.
