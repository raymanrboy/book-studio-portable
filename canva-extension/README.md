# Book Studio → Canva

Розширення для Chrome: розкладає книгу з Майстерні по її шаблону Canva. Картинки лягають у рамки сторінок,
на сторінках з текстом з'являється Yellow gradient sphere, а поверх неї текст (Schoolbell, 100). Вам лишається вирівняти.

## Встановити (один раз)

1. У Chrome відкрийте `chrome://extensions`.
2. Праворуч угорі увімкніть **«Режим розробника»**.
3. **«Завантажити розпаковане розширення»** → виберіть цю папку: `Book Studio\canva-extension`.
4. Відкрийте шаблон книги в Canva. Праворуч з'явиться помаранчева кнопка з книгою.

Після оновлення файлів у цій папці натисніть ↻ на картці розширення в `chrome://extensions` і перезавантажте вкладку Canva.

## Користуватися

1. Відкрийте копію шаблону книги в Canva. Внизу має бути видно стрічку сторінок («Сторінки»).
2. **Папка книги** → виберіть папку книги, наприклад `Book Studio\pipeline\books\33.guardian-angel`.
3. Перевірте полицю: обкладинка й розвороти. «T» означає, що на сторінці буде текст; клік по сторінці показує її текст.
4. **Сторінки**: за замовчуванням `1-31` (вся книга). Можна вписати `5-10` або `3,7,12`.
5. **Розкласти**. Поки йде розкладка, не чіпайте Canva.
6. Червона сторінка означає, що з нею щось не вийшло. Клікніть по ній, щоб прочитати причину. Натисніть «Розкласти» ще раз:
   готове не повториться.

Сфера береться з «Елементи → Нещодавно використані». Якщо розширення скаже, що її там немає, додайте її один раз руками.
