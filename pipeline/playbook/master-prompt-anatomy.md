# Master-Prompt Anatomy — що саме в ньому працює

`master-prompt.md` дався дорого через спроби й помилки. Цей файл пояснює, ЯКІ блоки несуть
результат, щоб його можна було тюнити свідомо, не ламаючи те, що працює.

**Головний урок:** verbose > minimal. Мінімалістичні «reference-only» промпти провалились —
персонаж не тримався, мережа генерувала навмання. Спрацював саме великий структурований
промпт із явними заборонами. Не «спрощуй» структуру промпта. Сам стиль навпаки тепер
навмисно спрощений: пастельна акварель, великі спокійні поля, прості форми, без hyper-detail.

## Load-bearing блоки (НЕ чіпати)

| Блок | Що ловить / навіщо | Якщо прибрати |
|---|---|---|
| `one uninterrupted 2:1 panoramic illustration` | тримає єдину суцільну сцену без фізичного layout-сигналу | мережа малює дві окремі картинки, рамку або фізичний об'єкт |
| **CHARACTER CONSISTENCY** — явний перелік рис | текстовий якір ідентичності | сам референс «усереднюється» → чужий персонаж |
| **Негативи тільки для тексту/стилю** (text / letters / 3D / vector / anime / photoreal / AI-look) | протидіють текстовому шуму й стилю, не називаючи фізичний формат | модель може зачепитися за названий forbidden concept і намалювати його |
| **TEXT SAFE AREA** (бік + «no text/letters», частина сцени) | лишає чисте місце під текст як illustrated negative space без «порожнього прямокутника» | текст-зона стає білою діркою, рамкою або обрубаною половиною |
| **2:1 + full bleed + AR-рядок** | формат розвороту під друк | неправильні пропорції, обрізання на верстці |
| Зони **story left / calm text area right** | жива панорама: головний фокус з одного боку, а середовище м'яко продовжується через текстову сторону | різкий шов між сценою й текст-зоною, порожня половина або prompt leakage |
| **Square end-image contract** | окремі 1:1 Dedication/Afterword з декоративними кутами й спокійним центром | спільна 2:1 генерація тягне центральний стик або складний slicing |
| **Simplified pastel watercolor / low detail density** | тримає стиль Book 01: м'яко, дитячо, апскейлер-friendly | кадри стають гіпердеталізовані, шумні, менш Etsy-nursery |

## Змінні блоки (наповнює Агент 5 даними агентів)
- SCENE DESIGN — зі story-blueprint (WHAT + props + focal point)
- LIGHTING — visual-world-bible + настрій розвороту
- EMOTIONAL GOAL — емоція зі story-blueprint
- CHARACTER — character-card (Tier H) або постать сцени (Tier S)
- VISUAL STYLE — global bible + blueprint's visual header (палітра)
- бік: головний обʼєкт ліворуч, текст-зона праворуч — завжди (без чергування; під водяний знак Gemini справа). У production prompt не копіювати відсотки, `LEFT/RIGHT`-ярлики, arrows, guide marks, або схемну мову, бо модель може це намалювати.

## Окремі уроки з тестів
- **Two-pass «згенеруй сцену, потім заміни дитину» — провал:** друга ітерація тримає
  реалістичну кісткову структуру, chibi не з'являється. Генеруй ВІДРАЗУ з повним промптом.
- **Фінальний wide image:** НЕ називаємо фізичний формат навіть у negatives. Формулюй позитивно:
  одна standalone 2:1 панорама; головний фокус праворуч; тихіше продовження середовища ліворуч;
  спокійна зона зверху праворуч для майбутньої типографіки. Контраст/насиченість можна підняти
  трохи вище за story-панорами, щоб працювало в Etsy-превʼю.
- Tier S (антологія): консистентність несе ТІЛЬКИ стиль; персонажа-якоря немає.
- **Book 01 God's Love стиль став house style:** найкраще спрацювала не “ultra detailed”
  акварель, а проста пастельна nursery-акварель із великим повітрям, smooth washes, одним
  маленьким фокусом і мінімумом деталей.

## Центральна лінія — як прибрати
Gemini/Nano Banana малює вертикальну лінію по центру 2:1, коли в generator-facing prompt бачить
фізично-видавничі слова. Лікування:
- Кадруй як **одну широку ПАНОРАМУ 2:1**, суцільну сцену від краю до краю.
- Не називай фізичний формат і не клади ці слова в negatives. Модель може намалювати навіть те,
  що ти просиш не малювати.
- Центр кадру = звичайна суцільна сцена (трава/листя/небо), без жодної позначки стику.
Це важливо ще й тому, що далі Майстерня Book Studio ріже 2:1 рівно по центру — лінія
зіпсувала б обидві половини.

## Правило тюнінгу
Міняй лише змінні блоки й палітру. Не прибирай low-detail / simple-pastel language, бо це тепер
частина базового стилю. Якщо чіпаєш load-bearing блок — тестуй на 1 розвороті
перш ніж гнати всю книгу.
