# Book Studio Portable — роудмап

Мета: одна папка, яку можна віднести на інший ПК й запустити, без встановлення чого-небудь. Усе потрібне лежить
усередині; якщо чогось бракує — програма сама каже, чого саме і що зробити (залогінитись тощо).

Рішення власника (03.10.2026): ключі й `vault.json` копіюються як є; копіюємо «буквально все»; налаштування — наявні.
Оригінал `D:\Roman\Desktop\Book Studio` **не чіпаємо** — усі зміни лише в цій копії.

## Структура папки

```
Book Studio Portable/
  Start Book Studio.bat, Start with console.bat, Make desktop shortcut.bat, ПРОЧИТАЙ.md   копії з portable/ репозиторію (приховані)
  Book Studio/          репозиторій raymanrboy/book-studio-portable (код, wiki, pipeline, portable/, ROADMAP.md — цей файл) + app/data з даними й ключами (не в git)
  runtime/
    python/             Python 3.14 з усіма бібліотеками
    Photoshop/          портативний Photoshop CC 2019
    Templates/          трафарети макапів (копія, лише читання)
    Antigravity/app/    Antigravity 2.19.1;  data/user-data — його налаштування
    Ollama/             ollama + models (≈9 ГБ)
    Upscayl/            рушій апскейлу
    ffmpeg/
```
